# Status sheme D9

D9 je novi uređivi KiCad nacrt s razdvojenim strujnim i upravljačkim dijelom. Redoslijed BAT+ → kontakt K1 → R1||R2 → INA219 → BAT− izveden je prema korisnikovu opisu. Poznati GPIO: D5/GPIO14 relej, D4/GPIO2 SDA, D1/GPIO5 SCL, A0 mjerenje napona. Relejni tranzistor, zaštitna dioda, djelitelj i napajanje INA219 još nisu fizički potvrđeni i ne smiju se predstavljati kao izvedbena shema. OLED nije dio sklopa.

KiCad 10 nije dostupan za automatski ERC u radnom okruženju; struktura datoteke provjerena je samo sintaktički. Datoteke projekta izrađene su za lokalno otvaranje nakon raspakiravanja ZIP-a.
